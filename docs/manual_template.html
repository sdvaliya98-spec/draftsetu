વિભાગ ૧ DraftSetu નો પરિચય (Introduction & Complete Workflow)

DraftSetu (ડ્રાફ્ટસેતુ) એ ગુજરાતના મહેસૂલી, કાનૂની અને સોગંદનામા દસ્તાવેજોને સરળ, સચોટ અને ઝડપી રીતે તૈયાર કરવા માટેનું અદ્યતન દસ્તાવેજ ઓટોમેશન પ્લેટફોર્મ છે.

🔄 Complete Document Creation Workflow (સંપૂર્ણ દસ્તાવેજ નિર્માણ પ્રક્રિયા)
📄 Document Selection ➔ 📝 Data Input ➔ 👁️ Live Preview ➔ 💾 Save Draft ➔ 📑 PDF Preview ➔ 🔍 Review & Correction ➔ 💳 Credits / Wallet ➔ 🔒 Final Lock ➔ 📄 Final DOCX / PDF ➔ 📁 My Documents
💡 DraftSetu ની મુખ્ય વિશેષતાઓ:
• DOCX Template Engine: ૧૦૦% શુદ્ધ માઇક્રોસોફ્ટ વર્ડ આધારિત પ્રોફેશનલ ફોર્મેટિંગ.
• Live Synchronization: ફોર્મમાં ડેટા લખતાની સાથે જ જમણી બાજુ લાઈવ પ્રિવ્યૂમાં ત્વરિત અપડેટ.
• Repeater Groups: એક કરતાં વધુ પક્ષકારો, વારસદારો કે મિલકતોની વિગતો સરળતાથી ઉમેરો.
• Bilingual Gujarati Support: ગુજરાતી યુનિકોડમાં સરળ ટાઈપિંગ અને સચોટ પ્રિન્ટિંગ.

વિભાગ ૨ સાઇન-અપ અને લોગિન પ્રક્રિયા (Signup & Login)

DraftSetu ની તમામ સુવિધાઓનો ઉપયોગ કરવા, ડ્રાફ્ટ સાચવવા અને અંતિમ દસ્તાવેજો ડાઉનલોડ કરવા માટે વપરાશકર્તાનું એકાઉન્ટ હોવું આવશ્યક છે.

સ્ક્રીનશોટ ૧: DraftSetu અધિકૃત Login / Registration મોડલ GovHeader → Log In / Register
  1. ઉપરની હેડર પટ્ટીમાં આવેલા Log In / Register બટન પર ક્લિક કરો.
  2. નવા વપરાશકર્તા માટે Sign Up ટેબ પસંદ કરી નામ, ઈમેલ, મોબાઈલ અને પાસવર્ડ દાખલ કરો. (નોંધણી પર ૧૦૦ ફ્રી ક્રેડિટ્સ મળે છે).
  3. હયાત એકાઉન્ટ માટે Log In ટેબમાં વિગતો દાખલ કરી Log In બટન દબાવો.

વિભાગ ૩ હોમ પેજ અને દસ્તાવેજ શોધ (Home Navigation)

હોમ પેજ પરથી લોકપ્રિય ટેમ્પલેટો, મહેસૂલી અરજીઓ અને સોગંદનામા સરળતાથી શોધી શકાય છે.

સ્ક્રીનશોટ ૨: હોમ પેજ, સર્ચ બાર અને પોપ્યુલર દસ્તાવેજ કાર્ડ્સ Home Page Overview

વિભાગ ૪ Step 1 – Document Selection (દસ્તાવેજ પસંદગી)

તમારે જે દસ્તાવેજ તૈયાર કરવો હોય તે હેડર મેનૂમાંથી અથવા એડિટર ડ્રોપડાઉનમાંથી પસંદ કરો.

સ્ક્રીનશોટ ૩: GovHeader માંથી DOCUMENT SERVICES મેનૂ અને કેટેગરી પેનલ Header → DOCUMENT SERVICES
  1. હેડરમાં આવેલા DOCUMENT SERVICES મેનૂ પર ક્લિક કરી સોગંદનામા, પાવર ઓફ એટર્ની કે કરાર પસંદ કરો.
  2. અથવા એડિટર પેજમાં ડાબી બાજુ ટોચ પર આવેલા Template Selector માંથી સીધું ટેમ્પલેટ પસંદ કરો.

વિભાગ ૫ Step 2 – Data Input અને ફોર્મ ફીલ્ડ્સ (Data Entry)

ટેમ્પલેટ પસંદ કર્યા પછી, સિસ્ટમ આપમેળે ડાબી બાજુ ઇનપુટ ફોર્મ અને જમણી બાજુ પ્રિવ્યૂ લોડ કરે છે.

સ્ક્રીનશોટ ૪: એડિટર વર્કસ્પેસ – ડાબી બાજુ ફોર્મ ઇનપુટ્સ અને જમણી બાજુ લાઈવ પ્રિવ્યૂ Editor Workspace Layout

ફોર્મ ફીલ્ડ્સના પ્રકારો અને નિયમો:

ફીલ્ડ પ્રકાર ઉપયોગ અને વિગત મહત્વની સૂચના
Text Input નામ, સરનામું, હોદ્દો, ગામ, તાલુકો, જિલ્લો ગુજરાતી અથવા અંગ્રેજી બંને ભાષામાં ટાઈપ કરી શકાય છે.
Required Fields (*) લાલ ફુદડી (*) વાળી તમામ ફરજિયાત વિગતો આ ફીલ્ડ ખાલી હશે તો દસ્તાવેજ ફાઈનલ લોક થશે નહીં.
Date Field દસ્તાવેજની તારીખ, સોગંદનામા તારીખ કેલેન્ડરમાંથી યોગ્ય તારીખ પસંદ કરો.
Format Validation આધાર કાર્ડ, પાન કાર્ડ, મોબાઈલ નંબર આધાર ૧૨ અંક અને મોબાઈલ ૧૦ અંકનો જ માન્ય ગણાશે.
⚠️ અગત્યની સૂચના (Mandatory Rule):
કોઈપણ લાલ ફુદડી (*) વાળી જગ્યા ખાલી ન છોડવી. જો કોઈ ફરજિયાત વિગત ખૂટતી હશે તો સિસ્ટમ તમને લાલ બોક્સ દ્વારા ચેતવણી આપશે અને ભૂલ સુધારવા જણાવશે.

વિભાગ ૬ રીપીટર ફીલ્ડ્સ અને કંટ્રોલ્સ (Repeater Groups)

એક કરતાં વધુ પક્ષકારો, વારસદારો કે સાક્ષીઓની વિગતો ભરવા માટે રીપીટર ગ્રૂપ આપેલું છે.

સ્ક્રીનશોટ ૫: રીપીટર ગ્રૂપ કંટ્રોલ્સ – Add Row, Duplicate, Copy All, Delete Form Panel → Repeater Controls

• + Add Row: નવો પક્ષકાર ઉમેરો • Duplicate: વિગતો નકલ કરો • Copy All: બધું કોપી કરો • Delete: પંક્તિ કાઢી નાખો.

વિભાગ ૭ લાઈવ સિન્ક અને હાઇલાઇટ (Live Sync & Highlights)

જમણી બાજુના પ્રિવ્યૂ પેનલમાં ઉપર ત્રણ મહત્વના સ્વીચ કંટ્રોલ્સ આપેલા છે:

સ્ક્રીનશોટ ૬: Highlight Variables, Live Sync ટોગલ સ્વિચ અને Sync Preview બટન Preview Panel Header
  1. Highlight Variables: ચાલુ કરતાં દસ્તાવેજમાં ભરેલી તમામ વિગતો પીળા કલરમાં હાઇલાઇટ થાય છે.
  2. Live Sync: ચાલુ રાખવાથી ફોર્મમાં લખતાંની સાથે જ આપમેળે ૧ સેકન્ડમાં પ્રિવ્યૂ અપડેટ થાય છે.
  3. Sync Preview: જરૂર જણાય ત્યારે મેન્યુઅલી તાત્કાલિક પ્રિવ્યૂ અપડેટ કરવા માટેનું બટન.

વિભાગ ૮ Protected Document Preview અને સુરક્ષા

DraftSetu પર દસ્તાવેજ ડ્રાફ્ટિંગ દરમિયાન જમણી બાજુ દર્શાવવામાં આવતો પ્રિવ્યૂ એ માત્ર ચકાસણી માટેનો Protected Preview છે.

🔒 Protected Document Preview Notice:
"Preview only. Final document is available after Finalize. / આ માત્ર પ્રિવ્યૂ છે. અંતિમ દસ્તાવેજ Finalize કર્યા પછી ઉપલબ્ધ થશે."
પ્રિવ્યૂ પેનલમાં ટેક્સ્ટ સિલેક્શન, રાઈટ-ક્લિક કોપી અને માઉસ ડ્રેગિંગ સુરક્ષાના કારણોસર અક્ષમ (Disabled) કરેલ છે.

વિભાગ ૯ PDF Preview અને વોટરમાર્કનો અર્થ (Watermarked Preview)

દસ્તાવેજ પ્રિન્ટમાં કેવો દેખાશે, માર્જિન અને ફોન્ટ કેવા બેઠા છે તે જોવા માટે 📄 PDF Preview (પૂર્વદર્શન) બટન આપેલું છે.

સ્ક્રીનશોટ ૭: PDF Preview મોડલ – કેન્દ્રમાં ૪૫ ડીગ્રી પર વોટરમાર્ક સાથેનું વેરિફિકેશન PDF Preview Modal
🏷️ PDF Preview વોટરમાર્ક અંગે ખાસ સ્પષ્ટતા:
પીડીએફ પ્રિવ્યૂમાં દરેક પેજ પર નીચે મુજબનો વોટરમાર્ક અંકિત થયેલો હશે:
"DRAFTSETU • PREVIEW COPY • NOT FOR OFFICIAL USE"
ગુજરાતી અર્થ: "આ PDF માત્ર પ્રિવ્યૂ અને ચકાસણી માટે છે. તે અંતિમ અધિકૃત દસ્તાવેજ નથી."
આ પ્રિવ્યૂ કોપી કોઈપણ સરકારી કચેરી કે કોર્ટમાં રજૂ કરવા માટે માન્ય નથી. અંતિમ ક્લીન દસ્તાવેજ મેળવવા માટે દસ્તાવેજ Finalize કરવો ફરજિયાત છે.

વિભાગ ૧૦ Draft Save અને 10-Document Limit (Draft Save & 10-Document Limit)

જો તમે દસ્તાવેજ ભરવાનું કામ અધૂરું રાખવા માંગતા હો, તો સેવ ડ્રાફ્ટ (Save Draft) બટન પર ક્લિક કરો.

💾 10-Document Limit Rule (દસ્તાવેજ સાચવવાની મર્યાદા):

ગુજરાતી: DraftSetu માં એક user એક સમયે વધુમાં વધુ 10 saved documents રાખી શકે છે. જો 10 documents પહેલેથી saved હોય, તો નવું document save કરવા માટે પહેલા કોઈ existing document delete કરવું જરૂરી છે. Document delete કર્યા પછી ખાલી થયેલી જગ્યા પર નવું document save કરી શકાય છે. Saved documents My Documents / Document Vault માંથી manage કરી શકાય છે.

English: DraftSetu allows a user to keep a maximum of 10 saved documents at a time. If 10 documents are already saved, the user must delete an existing document before saving another document. Once a document is deleted, the available slot can be used to save a new document. Saved documents can be managed from My Documents / Document Vault.

વિભાગ ૧૧ Final Lock / Finalize અને ક્રેડિટ્સ પ્રક્રિયા (Final Lock)

બધી વિગતો અને PDF Preview ની ચકાસણી થઈ ગયા પછી દસ્તાવેજને અંતિમ સ્વરૂપ આપવા માટે Final Lock બટન દબાવો.

સ્ક્રીનશોટ ૮: વૉલેટ અને ક્રેડિટ્સ ડેશબોર્ડ – ક્રેડિટ બેલેન્સ અને રિચાર્જ પ્લાન Header → Wallet & Credits

Final Lock પ્રક્રિયાના મહત્વના નિયમો:

  1. ક્રેડિટ્સ ખર્ચ (Credit Cost): ટેમ્પલેટ લોક કરવા માટે નિર્ધારિત ક્રેડિટ્સ (સામાન્ય રીતે ૧૦ ક્રેડિટ્સ) વૉલેટમાંથી કપાત થાય છે.
  2. પરમેનન્ટ લોક (Permanent Lock): એકવાર દસ્તાવેજ Final Lock થઈ ગયા પછી તેમાં કોઈ સુધારો (Edit) થઈ શકશે નહીં. સ્ટેટસ LOCKED થઈ જશે.
  3. વૉલેટ રિચાર્જ: જો ક્રેડિટ ખૂટે તો વૉલેટ આઇકોન પર ક્લિક કરી Razorpay દ્વારા ક્રેડિટ પેક ખરીદી શકાય છે.

વિભાગ ૧૨ અંતિમ સ્વચ્છ DOCX / PDF ડાઉનલોડ (Final Documents)

દસ્તાવેજ Final Lock થયા પછી સિસ્ટમ બે પ્રકારની ૧૦૦% સ્વચ્છ, વોટરમાર્ક વગરની અધિકૃત ફાઈલો તૈયાર કરે છે:

ફાઇલ ફોર્મેટ લાક્ષણિકતા ઉપયોગ
Final Word (.DOCX) ૧૦૦% એડિટેબલ માઇક્રોસોફ્ટ વર્ડ ફાઇલ, કોઈ વોટરમાર્ક નહીં. ઓફિસમાં વધારાની કલમો ઉમેરવા, ફોન્ટ સાઇઝ બદલવા કે સ્ટેમ્પ પેપર પર પ્રિન્ટ સેટિંગ કરવા માટે.
Final Clean (.PDF) હાઇ-ડેફિનેશન પ્રિન્ટ-રેડી પીડીએફ, વોટરમાર્ક-મુક્ત. સીધી પ્રિન્ટ કાઢવા, ડિજિટલ સાઇન કરવા, અથવા પક્ષકારોને વોટ્સએપ/ઈમેલ દ્વારા મોકલવા માટે.
⏱️ Processing Time Notice:
• English: Processing time may vary depending on document size and system/server load.
• ગુજરાતી: દસ્તાવેજનું processing time documentના કદ અને system/server load પ્રમાણે બદલાઈ શકે છે.

વિભાગ ૧૩ My Documents / દસ્તાવેજ ફોલ્ડર (Vault)

તમારા તમામ ડ્રાફ્ટ્સ અને ફાઇનલ થયેલા દસ્તાવેજો એક જ જગ્યાએ સુરક્ષિત રહે છે.

સ્ક્રીનશોટ ૯: મારું દસ્તાવેજ ફોલ્ડર (My Documents Vault) – સેવ કરેલા ડ્રાફ્ટ્સ અને ડાઉનલોડ હિસ્ટ્રી Header → મારું દસ્તાવેજ ફોલ્ડર (MY DOCUMENTS)
  1. હેડરમાં આવેલા મારું દસ્તાવેજ ફોલ્ડર (MY DOCUMENTS) પર ક્લિક કરો.
  2. તમારા તમામ દસ્તાવેજો તારીખ, ટેમ્પલેટ નામ અને સ્ટેટસ (Draft / Locked) સાથે દેખાશે.
  3. જો ૧૦ દસ્તાવેજો ભરાઈ ગયા હોય તો જૂનો દસ્તાવેજ Delete કરી નવી જગ્યા ખાલી કરો.
  4. અધૂરા ડ્રાફ્ટને ફરી ખોલવા માટે ક્લિક કરો અથવા ફાઇનલ દસ્તાવેજમાંથી સીધી DOCX/PDF ફરી ડાઉનલોડ કરો.

Final Lock બટન દબાવતાં લાલ એરર આવે છે. કોઈ લાલ ફુદડી (*) વાળી જગ્યા ખાલી છે અથવા આધાર/મોબાઈલના અંક અધૂરા છે. લાલ બોક્સ વાળા ફીલ્ડ્સ ચેક કરો.
