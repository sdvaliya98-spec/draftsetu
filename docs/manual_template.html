વિભાગ ૧ DraftSetu નો પરિચય (Introduction & Complete Workflow)

DraftSetu (ડ્રાફ્ટસેતુ) એ ગુજરાતના મહેસૂલી, કાનૂની, સોગંદનામા અને સ્ટેમ્પ ડ્રાફ્ટિંગ દસ્તાવેજોને સરળ, સચોટ અને ઝડપી રીતે તૈયાર કરવા માટેનું અદ્યતન દસ્તાવેજ ઓટોમેશન પ્લેટફોર્મ છે.

🔄 Complete Document Creation Lifecycle (સંપૂર્ણ દસ્તાવેજ નિર્માણ પ્રક્રિયા)
📄 Document Selection ➔ 📝 Data Input ➔ 👁️ Live Preview ➔ 💾 Save Draft (0 Credits) ➔ 📑 PDF Preview (Watermarked) ➔ 🪙 Wallet Check ➔ 🔒 Final Lock ➔ 📄 Clean DOCX / PDF Download
💡 DraftSetu ની મુખ્ય વિશેષતાઓ:
• DOCX Engine: શુદ્ધ માઇક્રોસોફ્ટ વર્ડ આધારિત પ્રોફેશનલ ફોર્મેટિંગ અને ડાઉનલોડ.
• Live Synchronization: ફોર્મમાં ડેટા લખતાની સાથે જ જમણી બાજુ લાઈવ પ્રિવ્યૂમાં ત્વરિત અપડેટ.
• Session Isolation & Recovery: બ્રાઉઝર રિફ્રેશ કે અકસ્માતે બંધ થવા પર પણ ડ્રાફ્ટ આપમેળે રિકવર થાય છે.
• Bilingual Gujarati Support: ગુજરાતી યુનિકોડમાં સરળ ટાઈપિંગ અને સચોટ પ્રિન્ટિંગ.

વિભાગ ૨ સાઇન-અપ અને લોગિન પ્રક્રિયા (Signup & Login)

DraftSetu ની તમામ સુવિધાઓનો ઉપયોગ કરવા, ડ્રાફ્ટ સાચવવા અને અંતિમ દસ્તાવેજો ડાઉનલોડ કરવા માટે વપરાશકર્તાનું એકાઉન્ટ હોવું આવશ્યક છે.

સ્ક્રીનશોટ ૧: DraftSetu અધિકૃત Login / Registration મોડલ Header → Log In / Register
  1. ઉપરની હેડર પટ્ટીમાં આવેલા Log In / Register બટન પર ક્લિક કરો.
  2. નવા વપરાશકર્તા માટે Sign Up ટેબ પસંદ કરી નામ, ઈમેલ, મોબાઈલ અને પાસવર્ડ દાખલ કરો. (નોંધણી પર ૧૦૦ ફ્રી ક્રેડિટ્સ બોનસ મળે છે).
  3. હયાત એકાઉન્ટ માટે Log In ટેબમાં વિગતો દાખલ કરી Log In બટન દબાવો.

વિભાગ ૩ હોમ પેજ અને દસ્તાવેજ શોધ (Home Navigation)

હોમ પેજ પરથી લોકપ્રિય ટેમ્પલેટો, મહેસૂલી અરજીઓ અને સોગંદનામા સરળતાથી શોધી શકાય છે.

સ્ક્રીનશોટ ૨: હોમ પેજ, સર્ચ બાર અને પોપ્યુલર દસ્તાવેજ કાર્ડ્સ Home Page Overview

વિભાગ ૪ Step 1 – Document Selection (દસ્તાવેજ પસંદગી)

તમારે જે દસ્તાવેજ તૈયાર કરવો હોય તે હેડર મેનૂમાંથી અથવા એડિટર ડ્રોપડાઉનમાંથી પસંદ કરો.

સ્ક્રીનશોટ ૩: GovHeader માંથી DOCUMENT SERVICES મેનૂ અને કેટેગરી પેનલ Header → DOCUMENT SERVICES
  1. હેડરમાં આવેલા DOCUMENT SERVICES મેનૂ પર ક્લિક કરી સોગંદનામા, પાવર ઓફ એટર્ની કે કરાર પસંદ કરો.
  2. અથવા એડિટર પેજમાં ડાબી બાજુ ટોચ પર આવેલા Template Selector (#template-selector) માંથી સીધું ટેમ્પલેટ પસંદ કરો.

વિભાગ ૫ Step 2 – Data Input અને ફોર્મ ફીલ્ડ્સ (Data Entry)

ટેમ્પલેટ પસંદ કર્યા પછી, સિસ્ટમ આપમેળે ડાબી બાજુ ઇનપુટ ફોર્મ અને જમણી બાજુ પ્રિવ્યૂ લોડ કરે છે.

સ્ક્રીનશોટ ૪: એડિટર વર્કસ્પેસ – ડાબી બાજુ ફોર્મ ઇનપુટ્સ અને જમણી બાજુ લાઈવ પ્રિવ્યૂ Editor Workspace Layout

ફોર્મ ફીલ્ડ્સના પ્રકારો અને નિયમો:

ફીલ્ડ પ્રકાર ઉપયોગ અને વિગત મહત્વની સૂચના
Text Input નામ, સરનામું, હોદ્દો, ગામ, તાલુકો, જિલ્લો ગુજરાતી અથવા અંગ્રેજી બંને ભાષામાં ટાઈપ કરી શકાય છે.
Required Fields (*) લાલ ફુદડી (*) વાળી તમામ ફરજિયાત વિગતો આ ફીલ્ડ ખાલી હશે તો દસ્તાવેજ ફાઈનલ લોક થશે નહીં.
Date Field દસ્તાવેજની તારીખ, સોગંદનામા તારીખ Flatpickr કેલેન્ડરમાંથી યોગ્ય તારીખ પસંદ કરો.
Format Validation આધાર કાર્ડ, પાન કાર્ડ, મોબાઈલ નંબર આધાર ૧૨ અંક, પાન ૧૦ અક્ષર અને મોબાઈલ ૧૦ અંકનો જ માન્ય ગણાશે.
⚠️ અગત્યની સૂચના (Mandatory Rule):
કોઈપણ લાલ ફુદડી (*) વાળી જગ્યા ખાલી ન છોડવી. જો કોઈ ફરજિયાત વિગત ખૂટતી હશે તો સિસ્ટમ તમને લાલ બોક્સ દ્વારા ચેતવણી આપશે અને ભૂલ સુધારવા જણાવશે.

વિભાગ ૬ રીપીટર ફીલ્ડ્સ અને કંટ્રોલ્સ (Repeater Groups)

એક કરતાં વધુ પક્ષકારો, વારસદારો કે સાક્ષીઓની વિગતો ભરવા માટે રીપીટર ગ્રૂપ આપેલું છે.

સ્ક્રીનશોટ ૫: રીપીટર ગ્રૂપ કંટ્રોલ્સ – Add Row, Duplicate, Copy All, Delete Row Form Panel → Repeater Controls

• + Add Row: નવો પક્ષકાર/રો ઉમેરો • Duplicate: વિગતો નકલ કરો • Copy All: તમામ વિગતો કોપી કરો • Delete: પંક્તિ કાઢી નાખો.

વિભાગ ૭ લાઈવ સિન્ક અને હાઇલાઇટ (Live Sync & Highlights)

જમણી બાજુના પ્રિવ્યૂ પેનલમાં ઉપર ત્રણ મહત્વના સ્વીચ કંટ્રોલ્સ આપેલા છે:

સ્ક્રીનશોટ ૬: Highlight Variables, Live Sync ટોગલ સ્વિચ અને Sync Preview બટન Preview Panel Header
  1. Highlight Variables: ચાલુ કરતાં દસ્તાવેજમાં ભરેલી તમામ વિગતો પીળા કલરમાં હાઇલાઇટ થાય છે.
  2. Live Sync: ચાલુ રાખવાથી ફોર્મમાં લખતાંની સાથે જ આપમેળે ૧ સેકન્ડમાં પ્રિવ્યૂ અપડેટ થાય છે.
  3. Sync Preview: જરૂર જણાય ત્યારે મેન્યુઅલી તાત્કાલિક પ્રિવ્યૂ અપડેટ કરવા માટેનું બટન.

વિભાગ ૮ Protected Document Preview અને સુરક્ષા

DraftSetu પર દસ્તાવેજ ડ્રાફ્ટિંગ દરમિયાન જમણી બાજુ દર્શાવવામાં આવતો પ્રિવ્યૂ એ માત્ર ચકાસણી માટેનો Protected Preview છે.

🔒 Protected Document Preview Notice:
"Preview only. Final document is available after Finalize. / આ માત્ર પ્રિવ્યૂ છે. અંતિમ દસ્તાવેજ Finalize કર્યા પછી ઉપલબ્ધ થશે."
પ્રિવ્યૂ પેનલમાં ટેક્સ્ટ સિલેક્શન, રાઈટ-ક્લિક કોપી અને અનધિકૃત ઉપયોગ સુરક્ષાના કારણોસર અક્ષમ (Disabled) કરેલ છે.

વિભાગ ૯ PDF Preview અને વોટરમાર્કનો અર્થ (Watermarked Preview)

દસ્તાવેજ પ્રિન્ટમાં કેવો દેખાશે, માર્જિન અને ફોન્ટ કેવા બેઠા છે તે જોવા માટે 📄 PDF Preview (પૂર્વદર્શન) (#btn-pdf-preview-actions) બટન આપેલું છે.

સ્ક્રીનશોટ ૭: PDF Preview મોડલ – કેન્દ્રમાં ૪૫ ડીગ્રી પર વોટરમાર્ક સાથેનું વેરિફિકેશન PDF Preview Modal (#btn-pdf-preview-close)
🏷️ PDF Preview વોટરમાર્ક અંગે ખાસ સ્પષ્ટતા:
પીડીએફ પ્રિવ્યૂમાં દરેક પેજ પર નીચે મુજબનો વોટરમાર્ક અંકિત થયેલો હશે:
"DRAFTSETU • PREVIEW COPY • NOT FOR OFFICIAL USE"
ગુજરાતી અર્થ: "આ PDF માત્ર પ્રિવ્યૂ અને ચકાસણી માટે છે. તે અંતિમ અધિકૃત દસ્તાવેજ નથી."
આ પ્રિવ્યૂ કોપી કોઈપણ સરકારી કચેરી કે કોર્ટમાં રજૂ કરવા માટે માન્ય નથી. અંતિમ ક્લીન દસ્તાવેજ મેળવવા માટે દસ્તાવેજ Finalize / Final Lock કરવો જરૂરી છે.

વિભાગ ૧૦ Save Draft, સેશન આઇસોલેશન અને રિકવરી (Draft Lifecycle)

જો તમે દસ્તાવેજ ભરવાનું કામ અધૂરું રાખવા માંગતા હો અથવા ભરેલો ડેટા સુરક્ષિત કરવા માંગતા હો, તો સેવ ડ્રાફ્ટ (Save Draft) (#btn-save-draft) બટન દબાવો.

સ્ક્રીનશોટ ૮: સેવ ડ્રાફ્ટ, નવું દસ્તાવેજ (New Document) અને ક્રેડિટ ખર્ચ નોટિસ FormPanel Actions (#btn-save-draft, #btn-new-document)
💾 Draft Save ના મુખ્ય નિયમો અને ફાયદા:
• 0 Credits Consumed (ક્રેડિટ કપાત શૂન્ય): ડ્રાફ્ટ સેવ કરવાથી કોઈપણ ક્રેડિટ કપાતી નથી. ડ્રાફ્ટ ગમે તેટલી વાર એડિટ અને સેવ કરી શકાય છે.
• Tracking ID ફાળવણી: પહેલી વાર ડ્રાફ્ટ સેવ કરતાં જ સિસ્ટમ યુનિક Tracking ID (જેમ કે DOC-XXXXXXXX) ફાળવે છે.
• Browser Refresh Recovery: જો બ્રાઉઝર રિફ્રેશ થાય કે અચાનક ટેબ બંધ થાય, તો DraftCacheManager સક્રિય ટેમ્પલેટ માટે ભરેલો ડેટા આપમેળે પાછો લાવી આપે છે.

વિભાગ ૧૧ New Document અને સ્વતંત્ર સેશન્સ (New Document)

જ્યારે તમારે જૂના ડ્રાફ્ટને બદલે એકદમ નવો દસ્તાવેજ બનાવવો હોય, ત્યારે નવું દસ્તાવેજ (New Document) (#btn-new-document) બટન પર ક્લિક કરો.

  1. સંપૂર્ણ ક્લીયર: New Document ક્લિક કરવાથી ફોર્મના તમામ ખાનાઓ ખાલી થઈ જશે અને Tracking ID null થઈ જશે.
  2. સેશન આઇસોલેશન: જૂના ડ્રાફ્ટનો કોઈ ડેટા કે Tracking ID નવા દસ્તાવેજમાં મિક્સ થશે નહીં.
  3. સ્વતંત્ર ડ્રાફ્ટ્સ: તમે એકસાથે બહુવિધ અલગ-અલગ દસ્તાવેજોના ડ્રાફ્ટ્સ બનાવી શકો છો.

વિભાગ ૧૨ 10-Document Limit અને Custom Popup Dialog

DraftSetu એકાઉન્ટમાં વપરાશકર્તાની સંગ્રહ મર્યાદા જાળવવા માટે ૧૦-દસ્તાવેજ મર્યાદા (10-Document Limit) અમલમાં છે.

સ્ક્રીનશોટ ૯: DraftSetu Custom Popup Dialog – ૧૦ દસ્તાવેજ મર્યાદા ચેતવણી CustomDialog → 10-Document Limit Reached
⚠️ 10-Document Limit નિયમ (દસ્તાવેજ સાચવવાની મર્યાદા):

ગુજરાતી: DraftSetu માં એક user એક સમયે વધુમાં વધુ 10 saved documents રાખી શકે છે. જો 10 documents પહેલેથી saved હોય અને ૧૧મો ડ્રાફ્ટ સેવ કરવાનો પ્રયત્ન થાય, તો સિસ્ટમ નીચે મુજબનો કસ્ટમ ડાયલોગ પ્રદર્શિત કરે છે:

Title: 10-Document Limit Reached
Message: "તમારા accountમાં maximum 10 saved documents રાખી શકાય છે."
Secondary: "નવું document save કરવા માટે જૂના દસ્તાવેજો My Documents માંથી delete કરો અથવા Finalize કરો."

English: DraftSetu allows a user to keep a maximum of 10 saved documents at a time. If 10 documents are already saved, the user must delete an existing document from My Documents before saving another document. Once a document is deleted, the available slot can be used to save a new document.

વિભાગ ૧૩ Final Lock / Finalize અને ક્રેડિટ્સ કપાત પ્રક્રિયા

બધી વિગતો અને PDF Preview ની ચકાસણી થઈ ગયા પછી દસ્તાવેજને અંતિમ સ્વરૂપ આપવા માટે ફાઈનલ લોક કરો (Final Lock) (#btn-final-lock) બટન દબાવો.

સ્ક્રીનશોટ ૧૦: વૉલેટ અને ક્રેડિટ્સ ડેશબોર્ડ – ક્રેડિટ હિસાબ અને ઓનલાઇન રિચાર્જ Header → Wallet & Credits
🪙 ક્રેડિટ્સ કપાત અંગે મહત્વનો નિયમ (Important Credit Rule):

ગુજરાતી: "Final Lock વખતે લાગતા credits હાલમાં લાગુ document/template અને account configuration મુજબ દર્શાવવામાં આવે છે. Final Lock કરતાં પહેલાં Wallet/Credits sectionમાં દેખાતી current credit requirement ચકાસો."

English: "The credits required for Final Lock are determined by the current document/template/account configuration. Check the displayed Wallet/Credits requirement before confirming Final Lock."

Final Lock પ્રક્રિયાના મહત્વના મુદ્દા:

  1. ડુપ્લિકેટ કપાત સામે સુરક્ષા: Final Lock વખતે ક્રેડિટ માત્ર ૧ વાર જ કપાય છે. નેટવર્ક રીટ્રાય કે પેજ રીલોડ થવા પર બીજી વાર ક્રેડિટ કપાતી નથી.
  2. કાયમી લોક (Permanent Lock): Final Lock થયા પછી દસ્તાવેજ is_locked = true થઈ જશે અને તેમાં કોઈ ફેરફાર થઈ શકશે નહીં.
  3. વૉલેટ રિચાર્જ: જો વૉલેટમાં અપૂરતી ક્રેડિટ હશે, તો સિસ્ટમ લાલ ચેતવણી આપશે. Razorpay દ્વારા સુરક્ષિત રીતે વૉલેટ રિચાર્જ કરી શકાય છે.

વિભાગ ૧૪ અંતિમ સ્વચ્છ DOCX / PDF ડાઉનલોડ (Final Clean Documents)

દસ્તાવેજ Final Lock થયા પછી બેકએન્ડ એન્જિન આપમેળે બે પ્રકારની ૧૦૦% સ્વચ્છ, વોટરમાર્ક વગરની અધિકૃત ફાઈલો તૈયાર કરે છે:

સ્ક્રીનશોટ ૧૧: Final Lock પછી My Documents માં સ્વચ્છ PDF અને Word (.docx) ડાઉનલોડ બટન્સ My Documents → Download Actions
ફાઇલ ફોર્મેટ લાક્ષણિકતા ઉપયોગ અને સુવિધા
Final Word (.DOCX) ૧૦૦% એડિટેબલ માઇક્રોસોફ્ટ વર્ડ ફાઇલ, સંપૂર્ણ વોટરમાર્ક-મુક્ત. ઓફિસમાં વધારાની કલમો ઉમેરવા, ફોન્ટ સાઇઝ બદલવા કે સ્ટેમ્પ પેપર પ્રિન્ટિંગ સેટિંગ માટે.
Final Clean (.PDF) હાઇ-ડેફિનેશન પ્રિન્ટ-રેડી પીડીએફ, વોટરમાર્ક-મુક્ત. સીધી પ્રિન્ટ કાઢવા, ડિજિટલ સાઇન કરવા, પક્ષકારોને મોકલવા અથવા સબ-રજીસ્ટ્રાર કચેરીમાં રજૂ કરવા માટે.
⏱️ Processing Time Notice:
• English: Processing time may vary depending on document size and system/server load.
• ગુજરાતી: દસ્તાવેજનું processing time documentના કદ અને system/server load પ્રમાણે બદલાઈ શકે છે.

વિભાગ ૧૫ My Documents Vault અને ડ્રાફ્ટ એડિટ (Document Vault)

તમારા તમામ ડ્રાફ્ટ્સ અને ફાઇનલ થયેલા દસ્તાવેજો My Documents વૉલ્ટમાં કાયમી સંગ્રહિત રહે છે.

સ્ક્રીનશોટ ૧૨: મારું દસ્તાવેજ ફોલ્ડર – સેવ કરેલા ડ્રાફ્ટ્સ, લોક્ડ દસ્તાવેજો અને સર્ચ બાર Header → My Documents (#gov-header-my-docs-btn)
  1. હેડરમાં આવેલા My Documents (મારા દસ્તાવેજો) પર ક્લિક કરો.
  2. દરેક કાર્ડ પર Tracking ID, ટેમ્પલેટ નામ, છેલ્લી તારીખ અને સ્ટેટસ (DRAFT અથવા LOCKED) દેખાશે.
  3. ડ્રાફ્ટ એડિટ કરો (Edit Draft): ડ્રાફ્ટ કાર્ડ પર ક્લિક કરવાથી તે આપમેળે એડિટરમાં લોડ થઈ જશે અને તમામ ભરેલી વિગતો પૂર્વવત થઈ જશે.
  4. ડિલીટ કરો (Delete): ૧૦ દસ્તાવેજો પૂરા થઈ ગયા હોય ત્યારે જૂના બિનજરૂરી દસ્તાવેજને ડિલીટ કરી નવો સ્લોટ ખાલી કરી શકાય છે.
  5. ફરી ડાઉનલોડ: ફાઇનલ લોક થયેલા દસ્તાવેજો કોઈપણ સમયે ફરીથી DOCX કે PDF માં ડાઉનલોડ કરી શકાય છે.

દસ્તાવેજ Final Lock કરતાં પહેલાં નીચે આપેલા મુદ્દાઓની અચૂક ચકાસણી કરી લેવી:

પક્ષકારોના નામ અને જોડણી: આધાર કાર્ડ / ચૂંટણી કાર્ડ મુજબ ગુજરાતી અને અંગ્રેજી નામની જોડણી સાચી છે?
આધાર / પાન નંબર / મોબાઈલ: તમામ ઓળખ પુરાવાના આંકડા બરાબર ૧૨ / ૧૦ અંકના દાખલ થયેલ છે?
મિલકતની વિગતો / સરવે નંબર: ગામ નમૂના નં. ૭/૧૨ મુજબ સરવે નંબર, ખાતા નંબર અને ક્ષેત્રફળ સાચું છે?
PDF Preview ચકાસણી: વોટરમાર્ક્ડ PDF Preview ખોલીને લાઇન સ્પેસિંગ અને પેજ બ્રેક ચકાસ્યું?
વૉલેટ બેલેન્સ ચકાસણી: Final Lock માટે જરૂરી ક્રેડિટ્સ ઉપલબ્ધ છે તેની ચકાસણી કરી?

સમસ્યા (Issue) ઉકેલ (Solution)
Final Lock બટન દબાવતાં લાલ એરર આવે છે. કોઈ લાલ ફુદડી (*) વાળી જગ્યા ખાલી છે અથવા આધાર/મોબાઈલના અંક અધૂરા છે. લાલ બોક્સ વાળા ફીલ્ડ્સ ચેક કરો.

10 Document Limit Dialog દેખાય છે. My Documents માં જઈ જૂનો બિનજરૂરી દસ્તાવેજ Delete કરો જેથી નવી સ્લોટ ખાલી થઈ જાય.
અપૂરતી ક્રેડિટ (Insufficient Credits) મેસેજ આવે છે. વૉલેટમાં જરૂરી ક્રેડિટ નથી. હેડરમાં વૉલેટ આઇકોન પર ક્લિક કરી ક્રેડિટ પેક રિચાર્જ કરો.
પ્રિવ્યૂ લોડ થતો નથી (No preview loaded). ફોર્મમાં ૨-૩ વિગતો ભરો અથવા ઉપરનું Sync Preview બટન દબાવો.
બ્રાઉઝર બંધ થઈ ગયું પણ ડેટા પાછો લાવવો છે. ફરી સાઇટ ખોલી તે જ ટેમ્પલેટ પસંદ કરો. DraftCacheManager આપમેળે છેલ્લો ડ્રાફ્ટ રિકવર કરી આપશે.
